# AetherLab RFC reference assets

[Image 2: analysis workspace](./aetherlab-analysis.png) is a generated UX concept with illustrative data and behavior.

[RigExpert oracle](./rigexpert-oracle.md) and [source index](./rigexpert-source-index.md) provide the research reference. The [offline bundle](./rigexpert-reference-bundle.zip) contains the complete pinned source snapshot, original MIT notice, manifest and documentation consistency checker. Extract it and run python3 rigexpert/verify_oracle.py to check the archived evidence.

These assets support RFC review. They do not implement the application or establish hardware, bridge or RF validation.
